# Google Maps JavaScript Sample

## 3d-map-nadir-view

Display a top-down (nadir) perspective of a 3D map in roadmap mode.

## Setup

### Before starting run:

`npm i`

### Run an example on a local web server

`cd samples/3d-map-nadir-view`
`npm start`

### Build an individual example

`cd samples/3d-map-nadir-view`
`npm run build`

From 'samples':

`npm run build --workspace=3d-map-nadir-view/`

### Build all of the examples.

From 'samples':

`npm run build-all`

### Run lint to check for problems

`cd samples/3d-map-nadir-view`
`npx eslint index.ts`
