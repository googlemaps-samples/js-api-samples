# Google Maps JavaScript Sample

## marker-clustering

Marker Clustering

## Setup

### Before starting run:

`npm i`

### Run an example on a local web server

`cd samples/marker-clustering`
`npm start`

### Build an individual example

`cd samples/marker-clustering`
`npm run build`

From 'samples':

`npm run build --workspace=marker-clustering/`

### Build all of the examples.

From 'samples':

`npm run build-all`

### Run lint to check for problems

`cd samples/marker-clustering`
`npx eslint index.ts`
