# Google Maps JavaScript Sample

## streetview-simple

Street View split-map-panes

## Setup

### Before starting run:

`npm i`

### Run an example on a local web server

`cd samples/streetview-simple`
`npm start`

### Build an individual example

`cd samples/streetview-simple`
`npm run build`

From 'samples':

`npm run build --workspace=streetview-simple/`

### Build all of the examples.

From 'samples':

`npm run build-all`

### Run lint to check for problems

`cd samples/streetview-simple`
`npx eslint index.ts`
