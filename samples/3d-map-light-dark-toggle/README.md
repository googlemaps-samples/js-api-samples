# Google Maps JavaScript Sample

## 3d-map-light-dark-toggle

Toggle a 3D map between light and dark mode in roadmap mode, overriding the system setting.

## Setup

### Before starting run:

`npm i`

### Run an example on a local web server

`cd samples/3d-map-light-dark-toggle`
`npm start`

### Build an individual example

`cd samples/3d-map-light-dark-toggle`
`npm run build`

From 'samples':

`npm run build --workspace=3d-map-light-dark-toggle/`

### Build all of the examples.

From 'samples':

`npm run build-all`

### Run lint to check for problems

`cd samples/3d-map-light-dark-toggle`
`npx eslint index.ts`
